# جستجوی کامل محصولات اسنپ‌فود

یک Userscript رایگان برای جمع‌آوری و جستجو میان تمام محصولات فهرست‌های اسنپ‌فود؛ حتی محصولاتی که هنوز با اسکرول بارگذاری نشده‌اند.

> **توجه:** این پروژه مستقل و غیررسمی است و هیچ وابستگی، همکاری، حمایت یا تأییدی از سوی اسنپ‌فود ندارد. نام اسنپ‌فود فقط برای توضیح سازگاری ابزار با وب‌سایت آن استفاده شده است.

**نسخهٔ فعلی: `1.8.4`**

## امکانات

- دریافت سریع محصولات فودپارتی از API مورد استفادهٔ وب‌سایت اسنپ‌فود و استفاده از روش اسکرول به‌عنوان جایگزین
- جستجو در نام غذا و نام رستوران
- نمایش قیمت، درصد تخفیف، امتیاز و هزینهٔ پیک
- نمایش نتایج فقط بعد از واردکردن عبارت جستجو
- کلیک روی کارت نتیجه برای بازکردن صفحهٔ داخلی مشاهده و سفارش همان محصول
- پشتیبانی از فودپارتی، اکونومی و دیگر صفحات دارای کارت محصول
- پشتیبانی از دامنهٔ `snappfood.ir` و زیردامنه‌هایی مانند `superapp` و `m`
- رابط فارسی و سازگار با موبایل
- میانبر `Ctrl + Shift + F`
- بدون سرور، API Key، ردیابی یا ارسال اطلاعات به سرویس دیگر

## نصب کامل در Google Chrome

### مرحلهٔ ۱: نصب Tampermonkey

افزونهٔ رسمی Tampermonkey را از Chrome Web Store نصب کنید:

### [دانلود Tampermonkey از Chrome Web Store](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo)

در صفحهٔ افزونه روی **Add to Chrome** و سپس **Add extension** بزنید.

### مرحلهٔ ۲: دادن مجوز اجرای Userscript به Tampermonkey

این مرحله در نسخه‌های جدید Chrome ضروری است. اگر آن را انجام ندهید، اسکریپت در Tampermonkey ذخیره می‌شود اما اجازهٔ اجرا روی اسنپ‌فود را ندارد.

1. آدرس `chrome://extensions` را در نوار آدرس Chrome باز کنید.
2. گزینهٔ **Developer mode** بالای صفحه را روشن کنید.
3. کارت افزونهٔ **Tampermonkey** را پیدا کنید و روی **Details** بزنید.
4. مطمئن شوید گزینهٔ **Allow User Scripts** روشن است.
5. در بخش دسترسی سایت یا **Site access**، گزینهٔ **On all sites** را انتخاب کنید؛ یا دسترسی اجرا روی `https://*.snappfood.ir/*` را بدهید.
6. اگر Chrome درخواست تأیید مجوز کرد، دسترسی دامنه‌های اسنپ‌فود را تأیید کنید.

اگر گزینهٔ **Allow User Scripts** را نمی‌بینید، بعد از روشن‌کردن Developer mode صفحهٔ Extensions را یک‌بار Refresh کنید.

### مرحلهٔ ۳: کپی‌کردن فایل JavaScript

فایل اصلی اسکریپت را از لینک زیر باز کنید:

### [مشاهدهٔ فایل snappfood-party-search.user.js در GitHub](./snappfood-party-search.user.js)

بعد از بازشدن فایل:

1. در صفحهٔ فایل GitHub روی دکمهٔ **Copy raw file** بزنید؛ یا ابتدا **Raw** را باز کنید.
2. اگر حالت Raw را باز کردید، تمام محتوا را با `Ctrl + A` و سپس `Ctrl + C` کپی کنید.

مطمئن شوید کد را از اولین خط `// ==UserScript==` تا آخرین خط فایل کامل کپی کرده‌اید.

### مرحلهٔ ۴: اضافه‌کردن کد به Tampermonkey

1. روی آیکن Tampermonkey در نوار ابزار Chrome بزنید.
2. گزینهٔ **Create a new script…** را انتخاب کنید.
3. در ویرایشگر بازشده، کد پیش‌فرض را با `Ctrl + A` کامل انتخاب و پاک کنید.
4. کدی را که در مرحلهٔ قبل کپی کردید با `Ctrl + V` جای‌گذاری کنید.
5. با `Ctrl + S` اسکریپت را ذخیره کنید.
6. وارد **Dashboard** تَمپرمونکی شوید و مطمئن شوید کلید مقابل «جستجوی کامل محصولات اسنپ‌فود» سبز و **Enabled** است.

### مرحلهٔ ۵: بررسی دوبارهٔ مجوزها

قبل از اجرای اسکریپت یک‌بار دیگر این موارد را کنترل کنید:

1. در `chrome://extensions` وارد **Tampermonkey → Details** شوید.
2. گزینهٔ **Allow User Scripts** باید روشن باشد.
3. در **Site access**، دسترسی اسنپ‌فود یا گزینهٔ **On all sites** باید فعال باشد.
4. در Dashboard خود Tampermonkey نیز اسکریپت باید **Enabled** باشد.

### مرحلهٔ ۶: تازه‌سازی اسنپ‌فود و شروع استفاده

1. یکی از صفحات محصولات اسنپ‌فود، مانند [فودپارتی](https://superapp.snappfood.ir/party/?dealProjectListId=23)، را باز کنید.
2. آدرس یا محله را انتخاب کنید و صبر کنید محصولات نمایش داده شوند.
3. صفحه را با `Ctrl + Shift + R` تازه‌سازی کنید.
4. بعد از بارگذاری صفحه، دکمهٔ صورتی **جستجوی همه** پایین صفحه نمایش داده می‌شود.
5. روی دکمه بزنید، منتظر پایان جمع‌آوری بمانید و سپس نام غذا یا رستوران را جستجو کنید.

اگر دکمه ظاهر نشد، ابتدا بخش **رفع اشکال** پایین همین README را بررسی کنید.

## روش استفاده

1. ابتدا آدرس یا محلهٔ خود را در اسنپ‌فود انتخاب کنید تا محصولات نمایش داده شوند.
2. روی دکمهٔ صورتی **جستجوی همه** بزنید؛ یا `Ctrl + Shift + F` را فشار دهید.
3. در اولین اجرا، دریافت کل محصولات خودکار شروع می‌شود. در صفحات فودپارتی این کار مستقیماً از API خود اسنپ‌فود انجام می‌شود.
4. بعد از پایان جمع‌آوری، نام غذا یا رستوران را در کادر جستجو تایپ کنید.
5. روی کارت نتیجه بزنید تا صفحهٔ داخلی مشاهده و سفارش همان محصول باز شود.

پس از جمع‌آوری، صفحه به موقعیت قبلی اسکرول برمی‌گردد. موجودی و تخفیف‌ها ممکن است تغییر کنند؛ برای دریافت اطلاعات تازه روی **بارگذاری دوباره** بزنید.

## رفع اشکال

### دکمهٔ جستجو ظاهر نمی‌شود

- مطمئن شوید محصولات صفحه کاملاً نمایش داده شده‌اند و آدرس یا محله انتخاب شده است.
- در `chrome://extensions` گزینهٔ **Allow User Scripts** برای Tampermonkey روشن باشد.
- دسترسی سایت Tampermonkey روی **On all sites** یا دامنهٔ اسنپ‌فود تنظیم شده باشد.
- در Dashboard، اسکریپت **Enabled** باشد.
- صفحه را با `Ctrl + Shift + R` تازه‌سازی کنید.

### Tampermonkey می‌گوید «has no access to this page»

از صفحهٔ Extensions وارد **Tampermonkey → Details** شوید و دسترسی سایت را روی **On all sites** قرار دهید.

### بعد از بارگذاری نتیجه‌ای دیده نمی‌شود

این رفتار طبیعی است. برای خلوت‌ماندن پنل، نتایج فقط بعد از تایپ نام غذا یا رستوران نشان داده می‌شوند.

### تعداد محصولات کمتر از عدد بالای صفحه است

موجودی اسنپ‌فود لحظه‌ای است و بعضی محصولات ممکن است هنگام جمع‌آوری حذف شوند یا بارگذاری نشوند. چند لحظه بعد **بارگذاری دوباره** را بزنید.

## به‌روزرسانی

Tampermonkey به‌کمک `@updateURL` نسخه‌های جدید را خودکار بررسی می‌کند. برای بررسی دستی نیز می‌توانید در Dashboard از گزینهٔ **Check for userscript updates** استفاده کنید.

## حریم خصوصی

اسکریپت فقط اطلاعات همان صفحه را از رابط و API مورد استفادهٔ وب‌سایت اسنپ‌فود می‌خواند. هیچ اطلاعاتی به سرور یا سرویس دیگری ارسال نمی‌شود.

## وضعیت پروژه

این پروژه یک ابزار مستقل، متن‌باز و غیررسمی است. توسعه‌دهندهٔ این پروژه نماینده، شریک یا همکار اسنپ‌فود نیست و اسنپ‌فود این پروژه را تأیید یا پشتیبانی نکرده است. API استفاده‌شده همان API مشاهده‌شده در عملکرد وب‌سایت است و عبارت «رسمی» به معنای ارائهٔ عمومی یا صدور مجوز توسعه‌دهندگان برای آن نیست.

## توسعه

پروژه dependency یا مرحلهٔ build ندارد. فایل Userscript مستقیماً قابل نصب است. هنگام انتشار نسخهٔ جدید باید مقدار `@version` ابتدای فایل و نسخهٔ نوشته‌شده در README افزایش یابد.

## محدودیت

این ابزار به ساختار فعلی رابط وب اسنپ‌فود وابسته است. اگر اسنپ‌فود ساختار کارت‌ها یا صفحه‌بندی را تغییر دهد، selectorها نیز ممکن است به به‌روزرسانی نیاز داشته باشند.
