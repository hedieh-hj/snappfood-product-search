# جستجوی کامل محصولات اسنپ‌فود

یک Userscript سبک برای جستجو میان **تمام محصولات صفحات اسنپ‌فود**؛ حتی محصولاتی که هنوز با اسکرول بارگذاری نشده‌اند. اسکریپت روی دامنه اصلی و تمام زیردامنه‌های `snappfood.ir` فعال است، اما دکمه را فقط وقتی نمایش می‌دهد که صفحه واقعاً کارت محصول داشته باشد.

## امکانات

- جمع‌آوری خودکار کل لیست با درنظرگرفتن بارگذاری تدریجی
- پشتیبانی از فودپارتی، اکونومی و سایر صفحات دارای کارت محصول
- پشتیبانی از `snappfood.ir` و زیردامنه‌هایی مانند `superapp` و `m`
- جستجوی هم‌زمان در نام غذا و نام رستوران
- نمایش نتایج فقط پس از واردکردن عبارت جستجو
- نمایش تخفیف، قیمت و امتیاز هر محصول
- نمایش هزینهٔ پیک هر محصول
- کلیک روی نتیجه برای اسکرول به همان محصول در فهرست اصلی
- دکمهٔ جداگانه برای بازکردن مستقیم صفحهٔ محصول
- رابط فارسی، واکنش‌گرا و مناسب موبایل
- میانبر `Ctrl + Shift + F`
- بدون سرور، API key، ردیابی یا ارسال اطلاعات به سرویس دیگری

## نصب

1. افزونه [Tampermonkey](https://www.tampermonkey.net/) را روی مرورگر نصب کنید.
2. فایل [`snappfood-party-search.user.js`](./snappfood-party-search.user.js) را در حالت Raw باز کنید.
3. در صفحه Tampermonkey گزینه **Install** را بزنید.
4. وارد یکی از صفحات فهرست محصولات اسنپ‌فود، مانند [فودپارتی](https://superapp.snappfood.ir/party/?dealProjectListId=23)، شوید.

> بعد از قراردادن پروژه در GitHub، لینک Raw فایل را می‌توانید به‌عنوان لینک نصب یک‌کلیکی در README قرار دهید.

## استفاده

در هر صفحه‌ای که فهرست محصول داشته باشد، روی دکمه صورتی «جستجوی همه» در پایین صفحه بزنید یا `Ctrl + Shift + F` را فشار دهید. با اولین بازشدن پنل، جمع‌آوری محصولات به‌صورت خودکار آغاز می‌شود. صفحه باید تا پایان عملیات باز بماند؛ پس از اتمام، اسکرول به موقعیت قبلی برمی‌گردد. اگر صفحه برای نمایش محصولات به انتخاب آدرس یا محله نیاز داشته باشد، دکمه بعد از نمایش محصولات ظاهر می‌شود.

از آنجا که موجودی و تخفیف‌ها به آدرس انتخاب‌شده و زمان مراجعه وابسته‌اند، برای تازه‌کردن نتایج روی «بارگذاری دوباره» بزنید.

## توسعه و انتشار

پروژه به ابزار build یا dependency نیاز ندارد. فایل Userscript مستقیماً قابل نصب است. هنگام انتشار نسخه جدید، مقدار `@version` در ابتدای فایل را افزایش دهید.

اگر نام کاربری و نام مخزن GitHub را مشخص کردید، می‌توانید این دو خط را نیز به metadata فایل اضافه کنید تا به‌روزرسانی خودکار فعال شود:

```js
// @downloadURL  https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/snappfood-party-search.user.js
// @updateURL    https://raw.githubusercontent.com/USERNAME/REPOSITORY/main/snappfood-party-search.user.js
```

## محدودیت

این ابزار به ساختار فعلی رابط وب اسنپ‌فود وابسته است. اگر اسنپ‌فود آدرس صفحه یا ساختار لیست محصولات را تغییر دهد، ممکن است selectorها نیاز به به‌روزرسانی داشته باشند.
